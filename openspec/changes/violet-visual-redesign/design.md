## Context

Violet 当前的 DESIGN.md 是对 Apple 网站设计语言的直接提炼，包含纯黑底色 (`#000000`)、Apple Blue (`#0071e3`)、SF Pro 字体等参数。这套语言适合科技产品展示，但对一个面向南大学生的校园恋爱代聊平台来说过于冷峻。

前端现状：
- **登录页**（App.tsx）：纯黑底 + 三个输入框 + 一个按钮，缺少品牌感
- **聊天页**（ChatPage.tsx）：朴素的双面板布局，工具化视觉
- **组件**（ChatPanel、MessageInput、PresenceIndicator）：功能完整但视觉粗糙
- **CSS**（index.css）：已定义 Apple 色彩变量和 Tailwind 主题，但缺少 Violet 品牌色

设计哲学转变：
```
Apple:  "产品即雕塑" — 冷峻、精确、工业感
Violet: "对话即心跳" — 温暖、亲密、年轻感

保留：高对比度、精准排版、毛玻璃效果、克制用色
转变：色调暖化、Accent 年轻化、氛围浪漫化
```

## Goals / Non-Goals

**Goals:**

- 建立一套完整的 Violet 品牌视觉系统，作为 DESIGN.md 的更新
- 重新设计登录页，从"开发者工具"升级为"品牌入口"
- 重新设计聊天页面全部组件，提升视觉精致度
- 所有改动仅涉及 CSS/Tailwind 类名和 JSX 结构，不改变业务逻辑

**Non-Goals:**

- 不改变任何业务逻辑（Socket.io 事件、Zustand store、API 调用）
- 不引入新的 UI 组件库（纯 Tailwind + 手写 CSS）
- 不做响应式适配优化（当前聊天页假设桌面端使用）
- 不做深色/浅色主题切换（只做深色主调一套）
- 不改后端代码

## Decisions

### D1: 色彩体系 — 深玫瑰调色板

**选择**：以深玫瑰紫为暗色基调，紫罗兰/珊瑚色为 accent

**备选**：保持 Apple 纯黑 + 蓝、使用暖灰 + 橙色

**理由**：

```
┌─────────────────────────────────────────────────────────┐
│              Violet 色彩体系                             │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  基调（替代纯黑）                                         │
│  ├── 深底色:    #0c0a14  (极深紫黑，不冰冷)                │
│  ├── 卡片表面:  #1a1525  (深紫灰，有温度的暗色)             │
│  └── 输入框底:  #231e2e  (可辨识的表面层)                  │
│                                                         │
│  Accent（替代 Apple Blue）                               │
│  ├── 主 Accent: #8b5cf6  (紫罗兰，年轻且不浮夸)            │
│  ├── 悬停态:    #7c3aed  (稍深的紫罗兰)                    │
│  ├── 亮 Accent: #a78bfa  (浅紫罗兰，用于暗底上的次要元素)    │
│  └── 暖 Accent: #f472b6  (珊瑚粉，用于在线状态、通知等)     │
│                                                         │
│  文字                                                    │
│  ├── 主文字(暗底):  #f5f0ff  (暖白，不是纯白)              │
│  ├── 次要文字:      rgba(245, 240, 255, 0.5)             │
│  └── 弱化文字:      rgba(245, 240, 255, 0.3)             │
│                                                         │
│  功能色                                                  │
│  ├── 在线:     #34d399  (翡翠绿，保持辨识度)               │
│  ├── 系统消息: #a78bfa  (紫罗兰，不突兀)                   │
│  └── 待确认:   #fbbf24  (琥珀色，保留警示感)               │
│                                                         │
│  消息气泡                                                │
│  ├── 自己:    #8b5cf6  (紫罗兰底 + 暖白字)                 │
│  └── 对方:    #1f1b2e  (深紫底 + 浅紫字)                  │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

这个色彩体系保留了 Apple 的高对比度哲学（深底 + 亮字），但将色温从冷蓝调转为暖紫调。紫罗兰不是"芭比粉"那种幼稚感，而是有质感的年轻色调。

### D2: Typography — 保留 SF Pro 精度但调整权重分布

**选择**：继续使用 SF Pro（Apple 系统），但调整场景映射

**备选**：引入自定义 Google Font（如 Noto Sans SC + Playfair Display）

**理由**：
- SF Pro 在 macOS/iOS 上渲染效果最佳，南大学生群体以 Apple 设备为主
- SF Pro 的 optical sizing 特性无可替代
- 不引入外部字体意味着零加载延迟
- 通过调整 weight 和 color 即可改变气质，无需换字体

关键调整：
- 品牌名 "Violet" 使用 weight 300（更轻盈、更优雅）
- 页面标题从 weight 600 降至 500（减少"厚重感"）
- body 保持 400

### D3: 毛玻璃效果 — 贯穿导航和面板

**选择**：在聊天页顶部导航和双面板分隔处使用毛玻璃效果

**理由**：
- 这是 Apple 设计中最具辨识度的视觉元素
- 与 Violet 的深紫底色搭配时，毛玻璃会呈现出温暖的紫调半透明
- 实现方式：`backdrop-filter: blur(20px) saturate(180%)` + 紫调半透明底色

### D4: 微动效策略

**选择**：引入 `motion` 库（framer-motion 的新包名）用于关键交互动效

**备选**：纯 CSS transition/animation

**理由**：
- 登录页进入动画（品牌名渐显、表单 stagger 入场）用纯 CSS 难以编排
- 消息气泡的入场动画需要 stagger timing
- `motion` 的 `animate` prop 与 React 组件模型完美匹配
- 包体积 ~30KB gzipped，可接受

动效清单：
- 登录页：品牌名 fade-in → 副标题 slide-up → 表单 stagger-in → 按钮 scale
- 聊天页：消息气泡 slide-in + fade-in
- 模式切换：pill 切换时滑动高亮
- 在线状态：dot pulse 动画

### D7: DESIGN.md 更新策略

**选择**：在现有 Apple 设计分析的基础上，新增 "Violet Brand Extension" 章节，保留原有分析作为"基础设计原则"

**理由**：
- Apple 的排版和空间原则仍然适用，不需要删除
- 新增品牌专属内容（色彩映射、氛围描述、组件样式覆盖）比全面重写更高效
- 未来如果需要扩展其他页面，可以沿用同一文档

## Risks / Trade-offs

- **[紫色调的性别化联想]** → 紫色可能被认为过于"女性化"。缓解：深紫黑基调足够中性，紫罗兰 accent 只用于交互元素，整体不会显得"粉嫩"。
- **[与 Apple 设计差异过大]** → 偏离 Apple 风格后可能失去 DESIGN.md 原有的设计严谨性。缓解：保留所有排版参数（line-height、letter-spacing、spacing scale），只改变色温。
- **[motion 库的包体积]** → 新增约 30KB gzipped。缓解：Violet 是 SPA，首次加载后缓存，30KB 在现代网络下可忽略。
- **[深色背景上的可读性]** → 深紫底 + 暖白字需要确保对比度达标。缓解：所有文字颜色确保 WCAG AA 对比度 (>4.5:1)。
