## Context

Violet 当前的视觉系统基于 Apple 设计语言 + 紫罗兰色调扩展，采用极深紫黑底色（#0c0a14）和单一紫罗兰 accent（#8b5cf6）。用户反馈"颜色太深、很单调"。

现有实现涉及 6 个前端文件：
- `index.css`：CSS 变量定义
- `App.tsx`：登录页
- `ChatPage.tsx`：聊天页框架
- `ChatPanel.tsx`：消息面板 + 气泡
- `MessageInput.tsx`：输入框 + 颜文字选择器
- `PresenceIndicator.tsx`：在线状态指示

本次变更不涉及后端、API、或数据模型，纯粹是前端视觉层的重构。

## Goals / Non-Goals

**Goals:**
- 建立莫奈印象派风格的完整色彩系统，包含从莫奈画作提取的 5 色和谐色板
- 将整体视觉从深色主题转为温暖明亮的印象派主题
- 让用户第一眼感受到"光线穿透一切"的温暖氛围
- 保留现有交互逻辑和组件结构不变，只替换视觉层

**Non-Goals:**
- 不改变组件结构、状态管理、或交互逻辑
- 不引入新的第三方 UI 库
- 不涉及后端或 API 层变更
- 不做响应式适配的改进（保持现有布局）
- 不做暗色/亮色主题切换功能（单一主题）

## Decisions

### Decision 1: 色板来源 — 从莫奈画作直接提取

**选择**: 从莫奈的《睡莲》、《花园》、《日出·印象》等作品中提取关键色彩，定义 5 色和谐色板。

**色彩定义**:
- **莫奈蓝** `#6b8fa3` — 取自睡莲水面，主交互色（CTA、focus ring、自己消息气泡）
- **玫瑰** `#c47d8e` — 取自花园玫瑰，通知和特殊高亮
- **鼠尾草绿** `#6b8c5a` — 取自花园绿植，在线状态
- **金色** `#c4a35a` — 取自日落金色光，待确认状态
- **薰衣草** `#8e7db5` — 取自大气朦胧，次级交互

**理由**: 莫奈的色彩经过艺术家的直觉校准，天然具有和谐关系。使用真实画作色彩比人工调色更有机。

**备选方案**: 人工设计一套"温暖色板"→ 被否决，缺乏莫奈特有的朦胧感和色彩和谐。

### Decision 2: 明亮温暖底色 — 奶油色画布

**选择**: 主背景使用温暖奶油色 `#faf7f2`（取名 Canvas），而非纯白或浅灰。

**理由**: 莫奈的画布本身不是纯白，而是带有暖色调的底漆色。这比纯白更有温度，比深色更明亮，消除了用户"颜色太深"的抱怨。卡片和浮层使用纯白 `#ffffff`（取名 Lily）。

**备选方案**: 保持深色主题但变浅 → 被否决，用户明确表示当前设计"太暗"。

### Decision 3: 毛玻璃效果从紫调改为暖白调

**选择**: `rgba(255, 255, 255, 0.72)` + `backdrop-filter: blur(24px)` 作为新的毛玻璃效果。

**理由**: 在明亮底色上，白色半透明毛玻璃效果更自然，模拟光线穿透薄雾的印象派氛围。紫调毛玻璃在暗色主题上有效，但在明亮主题上显得突兀。

### Decision 4: 文字颜色从暖白转为深色

**选择**: 主文字 `#2e2a36`（温暖深灰/靛色），次文字 `#6e6880`，三级文字 `#9e98aa`。

**理由**: 明亮背景上使用深色文字是基本的可读性要求。选择带暖调的深灰而非纯黑，保持与莫奈色板的整体和谐。

### Decision 5: 登录页渐变从深紫聚光灯转为温暖金光

**选择**: 从中心的温暖金色（`#f5efe4`）向边缘的奶油色（`#faf7f2`）辐射，营造阳光穿透花园的氛围。

**理由**: 与深紫聚光灯的"夜间"感形成鲜明对比，新的金光渐变传达"清晨的花园"——温暖、充满希望、浪漫。

### Decision 6: 消息气泡重新配色

**选择**:
- 自己消息：莫奈蓝底（`#6b8fa3`）+ 白字
- 对方消息：暖奶油底（`#f0ebe3`）+ 深靛字（`#2e2a36`）
- 系统消息：薰衣草半透明底 + 薰衣草文字

**理由**: 莫奈蓝比紫罗兰更柔和、更自然。暖奶油色比深紫更温暖、更易读。

## Risks / Trade-offs

- [风险] 明亮主题可能让部分偏好暗色的用户不适 → 目前不做主题切换，后续可根据用户反馈添加
- [风险] 莫奈蓝色（#6b8fa3）的对比度需要验证 → 需要确保白字在莫奈蓝底上的对比度 >= 4.5:1（WCAG AA）
- [权衡] 色板从单色（紫罗兰）扩展到 5 色，增加了一致性维护成本 → 通过 CSS 变量统一管理，组件只引用变量名
