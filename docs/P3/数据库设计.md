### 1.3 关系说明表

| 关系 | 类型 | 说明 |
|------|------|------|
| User → Relationship | 一对多 | 一个用户可作为 user1 或 user2 参与多个关系 |
| User → Message | 一对多 | 一个用户可发送多条消息 |
| User → MatchRequest | 一对多 | 一个用户可发起/接收多个牵线请求 |
| User → WingmanTask | 一对多 | 一个用户可作为 client 发布任务，或作为 wingman 接取任务 |
| User → WingmanApplication | 一对多 | 一个军师可提交多个申请 |
| User → WingmanAssignment | 一对多 | 一个军师可被分配到多个关系 |
| User → Rating | 一对多 | 一个用户可提交多个评价（关联通过 relationshipId） |
| User → CheckinRecord | 一对多 | 一个用户有多条签到记录 |
| User → CreditLog | 一对多 | 一个用户有多条信用分调整日志 |
| Relationship → Message | 一对多 | 一个关系有多条消息 |
| Relationship → WingmanAssignment | 一对多 | 一个关系最多有 2 个军师分配 |
| Relationship → WingmanTask | 一对多 | 一个关系可有多个军师招募任务 |
| Relationship → Rating | 一对多 | 一个关系有多条评价 |
| WingmanTask → WingmanApplication | 一对多 | 一个任务有多个申请（级联删除） |
| Post → PostReply | 一对多 | 一个帖子有多条回复 |

## 二、建表 SQL（PostgreSQL 16）

```sql
-- =====================================================
-- Violet 数据库建表脚本
-- 数据库：PostgreSQL 16
-- ORM：Prisma 6（本 SQL 为等效手动建表语句）
-- =====================================================

-- 枚举类型定义
CREATE TYPE "UserRole" AS ENUM ('CLIENT', 'WINGMAN', 'ADMIN');
CREATE TYPE "RelationshipStatus" AS ENUM ('MATCHING', 'ICEBREAKING', 'FLIRTING', 'ENDED');
CREATE TYPE "WingmanMode" AS ENUM ('SOLO', 'PRIVATE', 'ASSIST');
CREATE TYPE "TaskStatus" AS ENUM ('OPEN', 'ASSIGNED', 'IN_PROGRESS', 'COMPLETED', 'CANCELLED');
CREATE TYPE "ApplicationStatus" AS ENUM ('PENDING', 'APPROVED', 'REJECTED');
CREATE TYPE "PostStatus" AS ENUM ('ACTIVE', 'CLOSED');
CREATE TYPE "MessageType" AS ENUM ('MAIN', 'PRIVATE', 'PENDING', 'SYSTEM');
CREATE TYPE "MatchRequestStatus" AS ENUM ('PENDING', 'ACCEPTED', 'REJECTED', 'EXPIRED');
CREATE TYPE "WingmanCertStatus" AS ENUM ('NONE', 'PENDING', 'APPROVED', 'REJECTED');

-- ==================== 用户表 ====================
CREATE TABLE "User" (
    "id"                TEXT NOT NULL DEFAULT gen_random_uuid()::text,
    "email"             TEXT NOT NULL,                          -- 南大校园邮箱（唯一，不可修改）
    "contactEmail"      TEXT,                                   -- 常用邮箱
    "nickname"          TEXT NOT NULL,
    "password"          TEXT NOT NULL,                          -- bcrypt 加密存储
    "avatar"            TEXT,
    "gender"            TEXT,
    "campus"            TEXT,
    "grade"             TEXT,
    "major"             TEXT,
    "interests"         TEXT[] DEFAULT '{}',                    -- 兴趣标签数组
    "declaration"       TEXT,                                   -- 恋爱宣言
    "cardImage"         TEXT,                                   -- 个性卡片图片路径
    "creditScore"       INTEGER NOT NULL DEFAULT 0,            -- 信用分
    "isActive"          BOOLEAN NOT NULL DEFAULT true,
    "lastActiveAt"      TIMESTAMP(3) NOT NULL DEFAULT CURRENT_TIMESTAMP,
    "roles"             "UserRole"[] DEFAULT ARRAY['CLIENT']::"UserRole"[],
    "wingmanCertStatus" "WingmanCertStatus" NOT NULL DEFAULT 'NONE',
    "wingmanCertCooldown" TIMESTAMP(3),                         -- 认证失败冷却截止时间
    "wechat"            TEXT,                                   -- 隐私字段：微信
    "qq"                TEXT,                                   -- 隐私字段：QQ
    "phone"             TEXT,                                   -- 隐私字段：手机号
    "createdAt"         TIMESTAMP(3) NOT NULL DEFAULT CURRENT_TIMESTAMP,
    "updatedAt"         TIMESTAMP(3) NOT NULL DEFAULT CURRENT_TIMESTAMP,

    CONSTRAINT "User_pkey" PRIMARY KEY ("id"),
    CONSTRAINT "User_email_key" UNIQUE ("email")
);

-- ==================== 关系表 ====================
CREATE TABLE "Relationship" (
    "id"         TEXT NOT NULL DEFAULT gen_random_uuid()::text,
    "user1Id"    TEXT NOT NULL,                                 -- 当事人1
    "user2Id"    TEXT NOT NULL,                                 -- 当事人2
    "status"     "RelationshipStatus" NOT NULL DEFAULT 'MATCHING',
    "createdAt"  TIMESTAMP(3) NOT NULL DEFAULT CURRENT_TIMESTAMP,
    "updatedAt"  TIMESTAMP(3) NOT NULL DEFAULT CURRENT_TIMESTAMP,

    CONSTRAINT "Relationship_pkey" PRIMARY KEY ("id"),
    CONSTRAINT "Relationship_user1Id_fkey" FOREIGN KEY ("user1Id") REFERENCES "User"("id") ON DELETE RESTRICT ON UPDATE CASCADE,
    CONSTRAINT "Relationship_user2Id_fkey" FOREIGN KEY ("user2Id") REFERENCES "User"("id") ON DELETE RESTRICT ON UPDATE CASCADE,
    CONSTRAINT "Relationship_user1Id_user2Id_key" UNIQUE ("user1Id", "user2Id")
);

-- ==================== 军师分配表 ====================
CREATE TABLE "WingmanAssignment" (
    "id"             TEXT NOT NULL DEFAULT gen_random_uuid()::text,
    "relationshipId" TEXT NOT NULL,
    "userId"         TEXT NOT NULL,                             -- 军师用户ID
    "side"           INTEGER NOT NULL,                          -- 1=当事人1的军师, 2=当事人2的军师
    "mode"           "WingmanMode" NOT NULL DEFAULT 'PRIVATE',
    "joinedAt"       TIMESTAMP(3) NOT NULL DEFAULT CURRENT_TIMESTAMP,
    "leftAt"         TIMESTAMP(3),                              -- 离开时间（null=仍在）

    CONSTRAINT "WingmanAssignment_pkey" PRIMARY KEY ("id"),
    CONSTRAINT "WingmanAssignment_relationshipId_fkey" FOREIGN KEY ("relationshipId") REFERENCES "Relationship"("id") ON DELETE RESTRICT ON UPDATE CASCADE,
    CONSTRAINT "WingmanAssignment_userId_fkey" FOREIGN KEY ("userId") REFERENCES "User"("id") ON DELETE RESTRICT ON UPDATE CASCADE,
    CONSTRAINT "WingmanAssignment_relationshipId_side_key" UNIQUE ("relationshipId", "side")
);

-- ==================== 军师任务表 ====================
CREATE TABLE "WingmanTask" (
    "id"             TEXT NOT NULL DEFAULT gen_random_uuid()::text,
    "clientId"       TEXT NOT NULL,                             -- 当事人ID
    "relationshipId" TEXT,                                      -- 关联关系ID（可空）
    "title"          TEXT NOT NULL,
    "description"    TEXT NOT NULL,
    "status"         "TaskStatus" NOT NULL DEFAULT 'OPEN',
    "wingmanId"      TEXT,                                      -- 最终选中的军师ID
    "createdAt"      TIMESTAMP(3) NOT NULL DEFAULT CURRENT_TIMESTAMP,
    "updatedAt"      TIMESTAMP(3) NOT NULL DEFAULT CURRENT_TIMESTAMP,

    CONSTRAINT "WingmanTask_pkey" PRIMARY KEY ("id"),
    CONSTRAINT "WingmanTask_clientId_fkey" FOREIGN KEY ("clientId") REFERENCES "User"("id") ON DELETE RESTRICT ON UPDATE CASCADE,
    CONSTRAINT "WingmanTask_wingmanId_fkey" FOREIGN KEY ("wingmanId") REFERENCES "User"("id") ON DELETE SET NULL ON UPDATE CASCADE,
    CONSTRAINT "WingmanTask_relationshipId_fkey" FOREIGN KEY ("relationshipId") REFERENCES "Relationship"("id") ON DELETE SET NULL ON UPDATE CASCADE
);

-- ==================== 军师申请表 ====================
CREATE TABLE "WingmanApplication" (
    "id"        TEXT NOT NULL DEFAULT gen_random_uuid()::text,
    "taskId"    TEXT NOT NULL,
    "wingmanId" TEXT NOT NULL,
    "status"    "ApplicationStatus" NOT NULL DEFAULT 'PENDING',
    "createdAt" TIMESTAMP(3) NOT NULL DEFAULT CURRENT_TIMESTAMP,

    CONSTRAINT "WingmanApplication_pkey" PRIMARY KEY ("id"),
    CONSTRAINT "WingmanApplication_taskId_fkey" FOREIGN KEY ("taskId") REFERENCES "WingmanTask"("id") ON DELETE CASCADE ON UPDATE CASCADE,
    CONSTRAINT "WingmanApplication_wingmanId_fkey" FOREIGN KEY ("wingmanId") REFERENCES "User"("id") ON DELETE RESTRICT ON UPDATE CASCADE,
    CONSTRAINT "WingmanApplication_taskId_wingmanId_key" UNIQUE ("taskId", "wingmanId")
);

-- ==================== 消息表 ====================
CREATE TABLE "Message" (
    "id"             TEXT NOT NULL DEFAULT gen_random_uuid()::text,
    "relationshipId" TEXT NOT NULL,
    "senderId"       TEXT NOT NULL,
    "content"        TEXT NOT NULL,
    "type"           "MessageType" NOT NULL DEFAULT 'MAIN',
    "targetUserId"   TEXT,                                      -- PRIVATE/PENDING 消息的目标用户
    "isSystem"       BOOLEAN NOT NULL DEFAULT false,
    "requireConfirm" BOOLEAN NOT NULL DEFAULT false,            -- 辅助模式：需当事人确认
    "confirmed"      BOOLEAN NOT NULL DEFAULT false,
    "createdAt"      TIMESTAMP(3) NOT NULL DEFAULT CURRENT_TIMESTAMP,

    CONSTRAINT "Message_pkey" PRIMARY KEY ("id"),
    CONSTRAINT "Message_relationshipId_fkey" FOREIGN KEY ("relationshipId") REFERENCES "Relationship"("id") ON DELETE CASCADE ON UPDATE CASCADE,
    CONSTRAINT "Message_senderId_fkey" FOREIGN KEY ("senderId") REFERENCES "User"("id") ON DELETE RESTRICT ON UPDATE CASCADE,
    CONSTRAINT "Message_targetUserId_fkey" FOREIGN KEY ("targetUserId") REFERENCES "User"("id") ON DELETE SET NULL ON UPDATE CASCADE
);

-- ==================== 牵线请求表 ====================
CREATE TABLE "MatchRequest" (
    "id"         TEXT NOT NULL DEFAULT gen_random_uuid()::text,
    "fromUserId" TEXT NOT NULL,
    "toUserId"   TEXT NOT NULL,
    "status"     "MatchRequestStatus" NOT NULL DEFAULT 'PENDING',
    "createdAt"  TIMESTAMP(3) NOT NULL DEFAULT CURRENT_TIMESTAMP,
    "updatedAt"  TIMESTAMP(3) NOT NULL DEFAULT CURRENT_TIMESTAMP,

    CONSTRAINT "MatchRequest_pkey" PRIMARY KEY ("id"),
    CONSTRAINT "MatchRequest_fromUserId_fkey" FOREIGN KEY ("fromUserId") REFERENCES "User"("id") ON DELETE RESTRICT ON UPDATE CASCADE,
    CONSTRAINT "MatchRequest_toUserId_fkey" FOREIGN KEY ("toUserId") REFERENCES "User"("id") ON DELETE RESTRICT ON UPDATE CASCADE
);

-- ==================== 评价表 ====================
CREATE TABLE "Rating" (
    "id"             TEXT NOT NULL DEFAULT gen_random_uuid()::text,
    "relationshipId" TEXT NOT NULL,
    "fromUserId"     TEXT NOT NULL,
    "toUserId"       TEXT NOT NULL,
    "score"          INTEGER NOT NULL,                          -- -1, 1, 2, 3
    "comment"        TEXT,
    "createdAt"      TIMESTAMP(3) NOT NULL DEFAULT CURRENT_TIMESTAMP,

    CONSTRAINT "Rating_pkey" PRIMARY KEY ("id"),
    CONSTRAINT "Rating_relationshipId_fkey" FOREIGN KEY ("relationshipId") REFERENCES "Relationship"("id") ON DELETE CASCADE ON UPDATE CASCADE,
    CONSTRAINT "Rating_relationshipId_fromUserId_toUserId_key" UNIQUE ("relationshipId", "fromUserId", "toUserId")
);

-- ==================== 帖子表 ====================
CREATE TABLE "Post" (
    "id"        TEXT NOT NULL DEFAULT gen_random_uuid()::text,
    "authorId"  TEXT NOT NULL,
    "title"     TEXT NOT NULL,
    "content"   TEXT NOT NULL,
    "status"    "PostStatus" NOT NULL DEFAULT 'ACTIVE',
    "createdAt" TIMESTAMP(3) NOT NULL DEFAULT CURRENT_TIMESTAMP,
    "updatedAt" TIMESTAMP(3) NOT NULL DEFAULT CURRENT_TIMESTAMP,

    CONSTRAINT "Post_pkey" PRIMARY KEY ("id"),
    CONSTRAINT "Post_authorId_fkey" FOREIGN KEY ("authorId") REFERENCES "User"("id") ON DELETE RESTRICT ON UPDATE CASCADE
);

-- ==================== 帖子回复表 ====================
CREATE TABLE "PostReply" (
    "id"        TEXT NOT NULL DEFAULT gen_random_uuid()::text,
    "postId"    TEXT NOT NULL,
    "authorId"  TEXT NOT NULL,
    "content"   TEXT NOT NULL,
    "createdAt" TIMESTAMP(3) NOT NULL DEFAULT CURRENT_TIMESTAMP,

    CONSTRAINT "PostReply_pkey" PRIMARY KEY ("id"),
    CONSTRAINT "PostReply_postId_fkey" FOREIGN KEY ("postId") REFERENCES "Post"("id") ON DELETE CASCADE ON UPDATE CASCADE,
    CONSTRAINT "PostReply_authorId_fkey" FOREIGN KEY ("authorId") REFERENCES "User"("id") ON DELETE RESTRICT ON UPDATE CASCADE
);

-- ==================== 签到记录表 ====================
CREATE TABLE "CheckinRecord" (
    "id"        TEXT NOT NULL DEFAULT gen_random_uuid()::text,
    "userId"    TEXT NOT NULL,
    "createdAt" TIMESTAMP(3) NOT NULL DEFAULT CURRENT_TIMESTAMP,

    CONSTRAINT "CheckinRecord_pkey" PRIMARY KEY ("id"),
    CONSTRAINT "CheckinRecord_userId_fkey" FOREIGN KEY ("userId") REFERENCES "User"("id") ON DELETE RESTRICT ON UPDATE CASCADE
);

-- ==================== 信用分调整日志表 ====================
CREATE TABLE "CreditLog" (
    "id"        TEXT NOT NULL DEFAULT gen_random_uuid()::text,
    "userId"    TEXT NOT NULL,                                  -- 被调整的用户
    "adminId"   TEXT NOT NULL,                                  -- 执行调整的管理员
    "amount"    INTEGER NOT NULL,                               -- 正数增加，负数扣减
    "reason"    TEXT NOT NULL,
    "createdAt" TIMESTAMP(3) NOT NULL DEFAULT CURRENT_TIMESTAMP,

    CONSTRAINT "CreditLog_pkey" PRIMARY KEY ("id"),
    CONSTRAINT "CreditLog_userId_fkey" FOREIGN KEY ("userId") REFERENCES "User"("id") ON DELETE RESTRICT ON UPDATE CASCADE,
    CONSTRAINT "CreditLog_adminId_fkey" FOREIGN KEY ("adminId") REFERENCES "User"("id") ON DELETE RESTRICT ON UPDATE CASCADE
);
```

## 三、索引设计

```sql
-- =====================================================
-- 索引设计及说明
-- =====================================================

-- 1. 消息表：按关系ID+时间查询（聊天记录加载，最高频查询）
CREATE INDEX "Message_relationshipId_createdAt_idx" ON "Message"("relationshipId", "createdAt");

-- 2. 牵线请求：按目标用户+状态查询（收到请求列表）
CREATE INDEX "MatchRequest_toUserId_status_idx" ON "MatchRequest"("toUserId", "status");

-- 3. 牵线请求：按发起用户+状态查询（发送请求列表）
CREATE INDEX "MatchRequest_fromUserId_status_idx" ON "MatchRequest"("fromUserId", "status");

-- 4. 帖子回复：按帖子ID+时间查询（回复列表排序）
CREATE INDEX "PostReply_postId_createdAt_idx" ON "PostReply"("postId", "createdAt");

-- 5. 签到记录：按用户+时间查询（判断今日是否已签到）
CREATE INDEX "CheckinRecord_userId_createdAt_idx" ON "CheckinRecord"("userId", "createdAt");

-- 6. 信用分日志：按用户+时间查询（用户信用历史）
CREATE INDEX "CreditLog_userId_createdAt_idx" ON "CreditLog"("userId", "createdAt");

-- 7. 信用分日志：按管理员+时间查询（管理员操作审计）
CREATE INDEX "CreditLog_adminId_createdAt_idx" ON "CreditLog"("adminId", "createdAt");
```

### 索引设计理由

| 索引 | 查询场景 | 选择理由 |
|------|---------|---------|
| Message(relationshipId, createdAt) | 加载聊天记录，最频繁的读操作 | 聊天页游标分页按时间倒序加载，复合索引避免排序 |
| MatchRequest(toUserId, status) | 用户查看收到的待处理请求 | 高频查询，status 过滤 + 分页需要索引支持 |
| MatchRequest(fromUserId, status) | 用户查看已发送的请求 | 同上，对称查询场景 |
| PostReply(postId, createdAt) | 帖子回复列表按时间排序 | 帖子详情页核心查询 |
| CheckinRecord(userId, createdAt) | 每日签到去重检查 | 精确匹配用户+日期范围，避免全表扫描 |
| CreditLog(userId, createdAt) | 用户信用历史查询 | 管理员查看用户详情时的关联查询 |
| CreditLog(adminId, createdAt) | 管理员操作审计 | 审计追踪需要 |

## 四、隐私数据处理

| 字段 | 存储方式 | 安全措施 |
|------|---------|---------|
| password | bcrypt 哈希（salt rounds = 10） | 不可逆加密，API 响应中通过 `sanitizeUser()` 剥离 |
| email | 明文（用于登录和校园身份验证） | 仅限 @smail.nju.edu.cn 后缀，API 不对外暴露 |
| wechat / qq / phone | 明文 | 仅在 FLIRTING（暧昧期）通过 `contactExchange` 事件交换给对方，普通 API 不返回 |
| contactEmail | 明文 | 用户主动填写，仅管理员和本人可见 |

### 信用分安全

- 信用分扣减使用原子操作（`updateMany` + 条件 `creditScore >= amount`），防止并发超扣
- 信用分变动通过事务保证一致性（签到：increment + 创建记录；管理员调整：increment + 创建日志）
