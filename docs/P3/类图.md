# Phase 3 - 类图设计

> Violet 校园恋爱辅助平台 - 后端核心类图

---

## 一、系统类图总览

Violet 后端采用 NestJS 模块化架构，每个业务领域封装为独立的 Module。核心类分为以下层次：

- **Controller 层**：处理 HTTP 请求路由和参数校验
- **Gateway 层**：处理 WebSocket 实时通信
- **Service 层**：封装核心业务逻辑
- **Guard 层**：认证和权限控制
- **数据层**：PrismaService 封装数据库访问

## 四、类之间的关系

### 4.1 关联关系（Association）

| 来源类 | 目标类 | 关系类型 | 说明 |
|--------|--------|---------|------|
| AuthController | AuthService | 单向关联 | Controller 委托业务逻辑给 Service |
| UserController | UserService | 单向关联 | 同上 |
| DiscoveryController | DiscoveryService | 单向关联 | 同上 |
| ChatController | ChatService, PresenceService, RoomService, ChatLifecycleService | 多向关联 | Chat 模块复杂度高，依赖 4 个 Service |
| ChatGateway | ChatService, RoomService, PresenceService, ChatLifecycleService | 多向关联 | Gateway 是最复杂的类，协调多个 Service |
| WingmanTaskController | WingmanTaskService, ChatGateway | 单向+反向引用(fowardRef) | 审批通过后通过 Gateway 推送通知 |
| CreditController | CreditService | 单向关联 | 简单委托 |
| AdminController | AdminService | 单向关联 | 简单委托 |

### 4.2 依赖关系（Dependency）

| 来源类 | 目标类 | 说明 |
|--------|--------|------|
| 所有 Service | PrismaService | Service 层通过 PrismaService 访问数据库 |
| DiscoveryService | CreditService | 牵线请求扣减信用分 |
| ChatLifecycleService | ChatService, RoomService, PresenceService | 生命周期转换需要多个 Service 协作 |
| PresenceService | Redis (ioredis) | 在线状态存储在 Redis |
| AuthService | bcrypt, jsonwebtoken | 密码加密和 JWT 签发 |
| UserService | bcrypt | 密码验证 |
| AdminGuard | JwtAuthGuard, PrismaService | 继承 JWT 认证并额外验证管理员角色 |

### 4.3 继承关系（Inheritance）

| 子类 | 父类 | 说明 |
|------|------|------|
| PrismaService | PrismaClient | 继承 Prisma 生成的数据库客户端 |
| AdminGuard | JwtAuthGuard | 在 JWT 认证基础上增加管理员角色检查 |
| ChatGateway | OnGatewayConnection, OnGatewayDisconnect | 实现 WebSocket 生命周期接口 |
| PresenceService | OnModuleDestroy | 实现模块销毁时关闭 Redis 连接 |

### 4.4 聚合关系（Aggregation）

| 整体 | 部分 | 说明 |
|------|------|------|
| ChatModule | ChatGateway, ChatService, RoomService, PresenceService, ChatLifecycleService, ChatController | Chat 模块聚合了 6 个核心类 |
| RoomMember | userId, role, wingmanMode | 房间成员信息由 RoomService 构造 |
| LifecycleEvent | type, relationshipId, message, contactExchange | 生命周期事件的数据结构 |
