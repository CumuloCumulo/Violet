## 四、项目简介

### 4.1 项目背景

大学校园中，学生存在真实的恋爱社交需求，但普遍面临"想谈恋爱但缺乏渠道"的困境。根据前期调研，超过1/3的学生正在寻找恋爱关系，超过1/3的学生在遇到恋爱问题时会寻求"军师"帮助，超过80%的人有过当军师或愿意当军师的经历。

### 4.2 产品定位

NJU代恋是一个面向南京大学学生的校园恋爱代聊平台。平台核心功能是通过"军师"（恋爱顾问）辅助"当事人"进行破冰和关系推进。平台定位为**非主力长线聊天平台**，重点在于破冰和建议，而非替代真实的社交互动。

### 4.3 核心业务流程

1. **牵线期**：双方匿名初步交流，了解基本标签信息
2. **破冰期**：双方确认后进入，军师可介入辅助（代聊、建议等）
3. **暧昧期**：当事人交换联系方式，转到微信/QQ等平台继续

### 4.4 核心功能

- 南大邮箱注册认证
- 双重身份（当事人/军师）
- 四人三边聊天室（当事人×2 + 军师×2）
- 军师三种介入模式（Solo代聊、私聊、辅助）
- 军师大厅与任务发布
- 信用分经济体系
- 帖子大厅（匿名求助）
- 活跃度标签展示

## 五、技术栈选型

| 层级 | 技术选型 | 说明 |
|------|----------|------|
| 前端框架 | React + Vite | 组件化开发，生态成熟，开发效率高 |
| 前端样式 | Tailwind CSS | Utility-first CSS框架，AI生成类名准确率高，适合vibe coding开发 |
| 状态管理 | Zustand | 轻量、简洁的React状态管理 |
| 后端框架 | NestJS (Node.js) | 模块化架构，完美支持TypeScript |
| 实时通信 | Socket.io | 支持Rooms机制，适合复杂聊天室场景 |
| 数据库 | PostgreSQL | 关系型数据库，支持ACID事务 |
| ORM | Prisma | TypeScript友好的ORM，开发体验优秀 |
| 缓存 | Redis | 活跃度统计、Session管理、防并发 |
| 邮件服务 | Nodemailer | 南大邮箱验证码发送 |

## 六、团队协作规范

### 6.1 沟通机制

- 每周至少一次线上/线下同步会议
- 使用微信群进行日常沟通
- 重要决策需在群内@全体成员确认

### 6.2 Git 分支策略

```
main (稳定版本)
  └── dev (开发主线)
       └── feature/xxx (功能分支)
       └── fix/xxx (修复分支)
```

### 6.3 Commit 规范

- 格式：`[阶段] 类型: 描述`
- 标注AI使用：`[AI-assisted]` 或 `[Human-written]`
- 示例：`[P1] feat[AI-assisted]: 完成用户管理用例图`

### 6.4 会议记录

每次会议记录时间、参与人、讨论内容、决议事项、待办事项，存档至 `docs/meetings/` 目录。
