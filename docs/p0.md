# Phase 0：项目启动与AI协作契约

周次：第1周1人均工时：6小时1团队总工时：24小时

## 一、本阶段目标

1．完成组队，明确团队成员的角色分工

2．选择并搭建AI工具链

3．签署《AI协作契约》，建立团队的AI使用规范

4．搭建项目基础设施（Git仓库、CI流水线）

## 二、任务说明

### 任务1：组队与角色分工（1.5小时）

4人一组，确定初始角色分工。本项目要求角色轮换，每个阶段至少更换一次主导角色，确保每位成员都有机会担任不同岗位。

**要求**：制作一份角色轮换计划表，标注每个阶段的主导角色分配。

### 任务2:AI工具选型（1.5小时）

团队讨论并选择本项目使用的AI工具链。需要考虑：

**需要选择的工具类型：**-AI编程助手（如GitHub Copilot、Cursor、Claude Code、通义灵码等）-AI对话工具（如ChatGPT、Claude、文心一言等，用于文档生成、需求分析）-AI代码审查工具（如CodeRabbit、Al Code Review等）-AI测试工具（如AI测试用例生成工具）

**选型要求：**-每种类型至少评估2个候选工具-记录选择理由（功能、易用性、成本、团队熟悉度）-记录不选择某工具的理由

### 任务3：签署《AI协作契约》（1小时）

团队共同制定并签署一份《AI协作契约》，明确以下内容：

**思考引导：**为什么需要这份契约？如果没有审查规则，可能会出现什么问题？请回忆课堂上讲到的“工具依赖而能力退化”现象。

### 任务4：搭建项目基础设施（2小时）

#### 1．创建Git仓库

。初始化项目仓库（GitHub/GitLab/Gitee 均可）

。配置·gitignore （根据选择的技术栈）

。编写 README.md（项目简介、团队成员、技术栈）

。确定分支策略（建议： $main+dev+feature分支)$ 

#### 2．搭建基础CI流水线

。配置自动化构建（可使用 GitHub Actions / GitLab CI）

。至少包含：代码编译检查＋代码风格检查

#### 3．初始化项目结构

。创建基础目录结构

。配置开发环境说明文档

## 三、AI反思任务

本阶段不要求提交正式的反思日志，但请完成以下思考练习：

练习：尝试用AI生成一份“团队章程＂或“项目 $\text {README"}$ 的初稿。然后对比团队实际讨论后的版本。思考：-AI生成的内容有哪些是通用的套话？-有哪些是只有你们团队自己讨论才能确定的内容？-这个对比对后续使用AI有什么启示？
