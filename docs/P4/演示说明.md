# 演示说明 — Violet 校园恋爱辅助平台

> Phase 4 可演示版本

---

## 一、环境要求

- Node.js >= 24
- pnpm >= 10
- PostgreSQL 16
- Redis 7

## 二、本地运行

### 1. 启动后端

```bash
cd server
cp .env.example .env
# 编辑 .env 填入数据库连接信息和 SMTP 配置
pnpm install
npx prisma migrate deploy
pnpm start:dev
```

服务启动在 `http://localhost:3000`

### 2. 启动前端

```bash
cd client
pnpm install
pnpm dev
```

前端启动在 `http://localhost:5173`

## 五、核心演示路径

### 路径 1：用户注册 → 完善资料 → 发现匹配（P0 核心流程）

1. **注册** — 打开登录页，点击注册，输入南大邮箱，获取验证码，设置昵称和密码
2. **完善资料** — 进入个人资料页，选择性别、校区、年级、兴趣标签，上传头像和性格卡片
3. **浏览发现** — 进入发现页，浏览其他用户的卡片（横向滑动画廊），查看兴趣标签和恋爱宣言
4. **发起牵线** — 点击心形按钮发起牵线请求（消耗 5 积分），等待对方响应

### 路径 2：接受匹配 → 四人聊天 → 军师介入（P0 核心流程）

5. **查看通知** — 被牵线方在通知页收到新请求，查看发起者信息
6. **接受请求** — 点击接受，系统自动创建关系并进入破冰聊天阶段
7. **聊天互动** — 双方进入四人聊天室，开始破冰对话
8. **军师申请** — 军师用户在军师大厅查看招募任务，申请加入
9. **军师审批** — 当事人审批军师申请，军师进入聊天室
10. **军师模式** — 切换 PRIVATE（仅看私聊）/ SOLO（代表发言）/ ASSIST（建议需确认）模式

### 路径 3：积分签到 → 密码管理 → 通知管理（P1 功能）

11. **每日签到** — 在个人页面点击签到，获得 3 积分
12. **修改密码** — 在设置页输入旧密码和新密码完成修改
13. **密码重置** — 在登录页点击忘记密码，通过邮箱验证码重置
14. **通知管理** — 查看通知列表，标记已读，查看未读计数

### 路径 4：管理后台（P0 功能）

15. **管理员登录** — 管理员查看平台用户列表
16. **积分调整** — 调整用户信用分
17. **平台统计** — 查看注册用户数、关系数等统计数据

## 六、技术亮点

1. **四人聊天架构** — 独创的双当事人+双军师聊天模式，三种军师干预模式
2. **实时通信** — 基于 Socket.io 的 WebSocket 实时消息、在线状态、通知推送
3. **事件驱动** — 通知系统通过 EventEmitter 解耦，ChatGateway 监听事件推送
4. **积分原子操作** — 使用 Prisma `updateMany` + 条件 WHERE 避免竞态条件
5. **沉浸式设计** — Ethereal Romance 设计系统，横向视差画廊，氛围光晕背景
