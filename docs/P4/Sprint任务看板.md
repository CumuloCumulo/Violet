## 三、风险与决策

### 已解决的风险

1. **WebSocket 多人聊天复杂性** — 通过拆分 RoomService、PresenceService、ChatLifecycleService 三个子服务解耦
2. **积分扣除竞态条件** — 使用 Prisma 的 `updateMany` 原子操作 + 二次校验
3. **bcrypt ESM 模块 Mock 问题** — 单元测试中通过 `vi.mock('bcrypt')` 全局 mock 解决

### 降级/延期决策

- P2 智能匹配和数据统计功能延期至 P6，不影响核心业务流程演示
