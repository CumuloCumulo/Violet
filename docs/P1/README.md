## 🚀 建议的行动顺序

### Week 1（现在开始）

1. **Day 1-2**: 发布问卷，开始收集数据
2. **Day 1**: 同时做AI对比实验（获取AI生成需求）
3. **Day 3-5**: 执行访谈，收集≥8人次数据
4. **Day 5**: 完成对比分析表

### Week 2

5. **Day 6-7**: 编写需求规格说明书
6. **Day 8-9**: 完成用例建模和用户故事

## 📌 关键提醒

1. **用户调研是基础** - 不要跳过真实调研，AI不能替代真实用户声音
2. **保存所有AI输出** - 这是对比分析的基础素材
3. **标注需求来源** - 需求规格说明书中必须标注每条需求的来源
4. **反思日志很重要** - 这是课程评分的重要组成部分（占30%）
